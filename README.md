# RYTA Grow Together

Build RYTA, a simple, beautiful, mobile-first agricultural labour marketplace for India.

Brand: RYTA

Tagline: Grow Together.

Design: forest green, fresh lime, and white. Clean, modern, welcoming, large readable text, simple buttons, and easy navigation for rural users. Make it work well on mobile phones.

Create three user experiences:

1. Farmer/manager: post a farm job with location, work type, date, wage, and number of workers needed. View applicants and confirm workers.

2. Farm owner: view farms, job postings, bookings, and worker costs.

3. Labourer: create a simple profile with name, skills, location, and availability. Browse jobs and apply.

For the first version, focus on this complete demo flow:

- A user chooses their role.

- A farmer posts a job.

- A labourer sees the job and applies.

- The farmer sees the application and confirms the worker.

Include realistic sample jobs in Karnataka, India, using rupees (₹). Add a clear home screen and role selection.

Make the buttons and demo flow interactive. Use sample data first so I can test the app without setting up accounts or services.

Do not add payments, complicated features, or paid integrations yet. Do not claim sample workers are real or verified.

I am a beginner and do not code. Build the first version for me and explain any next step in simple language.
